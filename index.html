Get set up in Studio

Four things to know before you write a single line.

⬇️

Install Studio

Download Roblox Studio from create.roblox.com. It's the free editor where you build and script games.

📜

Add a Script

In the Explorer, right-click ServerScriptService → Insert Object → Script. That's where server code lives.

🖥️

Open the Output

View → Output. This window shows your print() messages and any errors — your best friend for debugging.

▶️

Hit Play

Press Play to test your game and run scripts. Stop, tweak, repeat — that's the whole loop.

Lua / Luau basics

Tap any topic to expand it. Learn at your own pace.

1 Your first script & variables ▾

Every program starts with printing something. Variables store values you reuse later.

Lua 
-- Print to the Output window
print("Hello, Roblox!")

-- Variables (local = only used in this script)
local playerName = "Nova"
local score = 0
local isAlive = true

print(playerName, "has", score, "points")
2 Conditions (if / else) ▾

Make your game react to different situations with if statements.

Lua 
local health = 25

if health <= 0 then
    print("You died!")
elseif health < 30 then
    print("Low health — be careful!")
else
    print("You're healthy.")
end
3 Loops (for & while) ▾

Repeat actions without copy-pasting. Great for spawning, counting, and timers.

Lua 
-- Count from 1 to 5
for i = 1, 5 do
    print("Wave " .. i)
end

-- Repeat while a condition is true
local enemies = 3
while enemies > 0 do
    print("Enemy defeated!")
    enemies = enemies - 1
end
4 Functions ▾

Bundle reusable logic into named blocks you can call anytime.

Lua 
local function greet(name)
    return "Welcome, " .. name .. "!"
end

print(greet("Nova"))  -- Welcome, Nova!
5 Parts & the game world ▾

Everything in a Roblox game is an Instance. Create and change parts from code.

Lua 
-- Create a glowing red block
local part = Instance.new("Part")
part.Size = Vector3.new(4, 4, 4)
part.Position = Vector3.new(0, 10, 0)
part.BrickColor = BrickColor.new("Really red")
part.Anchored = true
part.Parent = workspace  -- add it to the world
6 Events (click, touch) ▾

Events let your game react to what players do. Connect a function to an event.

Lua 
local part = workspace.Button

part.Touched:Connect(function(hit)
    local human = hit.Parent:FindFirstChild("Humanoid")
    if human then
        print(hit.Parent.Name .. " touched the button!")
    end
end)
7 Tables (lists & data) ▾

Tables hold collections of values — inventories, scores, config, anything.

Lua 
local inventory = { "Sword", "Shield", "Potion" }

for index, item in ipairs(inventory) do
    print(index, item)
end

-- Key/value data
local player = { name = "Nova", level = 7 }
print(player.name, player.level)
8 Server vs Client & RemoteEvents ▾

The server is trusted and shared; the client is each player's screen. They talk through RemoteEvents — the key to safe multiplayer games.

  • Server Scripts → in ServerScriptService. Handle game logic & data.
  • LocalScripts → run on the player. Handle UI, input, camera.
  • Never trust the client — validate important actions on the server.
Lua · Server 
local event = Instance.new("RemoteEvent")
event.Name = "GiveCoins"
event.Parent = game.ReplicatedStorage

event.OnServerEvent:Connect(function(player, amount)
    print(player.Name .. " requested " .. amount .. " coins")
end)

Your learning roadmap

A realistic path from curious beginner to confident scripter.

Week 1

Foundations

Install Studio, print messages, variables, and if-statements. Build a part that changes color on touch.

Week 2

Logic & flow

Master loops, functions, and tables. Make a coin that gives points and respawns.

Week 3

The game world

Manipulate Instances, use Humanoids, and connect real events like Touched and MouseClick.

Week 4+

Multiplayer & UI

Learn client vs server, RemoteEvents, GUIs, and DataStores to save player progress. Ship your first game!

Habits of great scripters

Small things that make a huge difference.

🐞

Read the Output

Errors tell you the line number and what broke. Read them slowly — they're clues, not scary.

🧩

Build tiny, test often

Write a few lines, press Play, confirm it works, then add more. Never write 100 lines blind.

📛

Name things clearly

playerHealth beats x. Future-you will thank present-you.

🔒

Trust the server

Handle scores, currency, and rules on the server so cheaters can't fake them.
